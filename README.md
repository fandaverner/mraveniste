# Mraveniště 🐜

Budovatelská strategie v průřezu mraveništěm. Kopej chodby do neprozkoumané země, stavěj komory, starej se o zásoby a dostaň kolonii přes zimu.

**Hrát:** https://fandaverner.github.io/mraveniste/

- ⛏️ Kopat: táhni prstem hlínou
- 🏠 Stavět: komory za hlínu (další se odemykají s velikostí kolonie)
- 🐜 Kolonie: poměr kast, co sbírat a vojáci
- Hra se ukládá automaticky v prohlížeči.
